# Seguridad y datos sensibles

RASTRO CARRIER está diseñado como herramienta estática de apoyo. No almacena expedientes en un servidor del proyecto, pero los datos locales se guardan sin cifrar en `localStorage` y los enlaces externos pueden transmitir los términos de búsqueda al servicio abierto.

- No incluya información de investigaciones, datos personales, matrículas investigadas, informes, capturas ni expedientes en issues, discusiones, pull requests o repositorios públicos.
- No use datos reales en capturas, demostraciones o pruebas compartidas.
- Mantenga el navegador y el dispositivo bajo los controles de su organización y elimine los datos locales cuando proceda.
- Para comunicar una vulnerabilidad, use el canal privado de Security Advisories del repositorio si está habilitado. No publique detalles explotables antes de coordinar su corrección.

Este proyecto no es una caja fuerte, sistema de gestión de casos ni repositorio de evidencias.
